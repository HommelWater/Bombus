# Bombus
Self-hostable chat application named after the bumblebee.

Setup:
1. clone this repository.
2. ensure port 443 is open on your server.
3. ensure your domain is pointing to your server's IP address.
4. run 'bash create_vapid_keys.sh'.
5. run 'setup_stun_turn.sh'.
6. run 'setup.sh'.
7. login using username 'admin' and leave password empty.
8. invite your users via invite codes.
